# Duet 90-Second Demo Script

## Demo goal

Prove that WebMCP lets an agent turn a musical request into a real, playable lesson rather than a paragraph of advice.

## Before recording

- Use a 1440 × 900 browser window.
- Load the default Duet state and keep the agent connected.
- Confirm the browser can output sound.
- Confirm the microphone works if the optional singing beat will be recorded.
- Keep the exact prompt copied as a fallback.
- Close unrelated tabs and disable notifications.

## Exact prompt

> Load Minuet in G. Keep only the right hand, slow it to 70 percent, loop bars 1–4, add a one-bar count-in and metronome, highlight G4 A4 B4 C5 D5 as “Opening phrase · right hand,” and start practice. Read the transport and the first score page, then tell me exactly what changed.

## Timeline and narration

### 0–10 seconds — Start with the instrument

Visual: press several keys with the computer keyboard and show the realistic keys react.

Voiceover: “I can ask an agent how to practise a piece, but normally I still have to rebuild that advice inside a music app.”

### 10–22 seconds — Give one musical task

Visual: paste the exact prompt into the connected agent.

Voiceover: “Duet exposes 21 musical WebMCP tools, so the agent works with pieces, notes, bars, tempo, loops, practice, and transport instead of clicking guessed coordinates.”

### 22–42 seconds — Watch the lesson assemble

Visual: show Minuet in G load, tempo move to 70%, loop become 1–4, count-in become 1, metronome activate, and left hand disappear.

Voiceover: “One request becomes a complete four-bar right-hand lesson. Every change appears in the same studio I am playing.”

### 42–58 seconds — Make it playable

Visual: show highlighted keys and Practice step 1. Press the expected key and show the practice state advance.

Voiceover: “The agent does not just configure playback. It highlights the phrase and starts a lesson I can continue immediately with mouse, touch, or my computer keyboard.”

### 58–72 seconds — Show trustworthy state

Visual: point to the moving note strip, transport, 21-tool badge, and activity records.

Voiceover: “The agent can read the exact transport and a bounded page of score data. Every action is attributed, and oversized scores are paginated instead of silently cut off.”

### 72–84 seconds — Optional musical conversation

Visual: click **Sing**, vocalize a short clear phrase, stop, and ask the agent to play it back or answer it.

Voiceover: “Duet can also turn a sung monophonic phrase into notes that the agent can read and answer on the piano.”

### 84–90 seconds — End on the thesis

Visual: keep the full playable lesson and activity rail on screen.

Voiceover: “With WebMCP, the answer is no longer advice beside the instrument. The answer becomes the instrument.”

## Recording fallback

If the microphone is unreliable, omit the singing beat and spend those seconds showing pause, resume, seek, or a QWERTY-to-note label switch. Do not imply that real-device microphone validation was completed unless it was tested on the recording machine.

If browser audio cannot be captured by the recorder, keep the key reactions and transport visible and add a short on-screen note that audio requires a browser gesture.
